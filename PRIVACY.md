# Privacy Policy

Youtube Element Remover does not collect, sell, share, or transmit personal information.

## Data Collection

The extension does not collect:

- Personal information
- Browsing history
- Search history
- YouTube account information
- Video watch history
- Analytics or usage tracking data

## Local Extension Settings

The extension stores one setting in Chrome storage: whether hiding distracting YouTube elements is turned on or off.

This setting is used only to remember the user's toggle preference. If Chrome sync is enabled, Chrome may sync this setting between the user's own browser instances according to the user's Chrome account settings.

## Network Requests

The extension does not send data to external servers and does not make external network requests.

## Permissions

The extension uses the `storage` permission only to save the on/off toggle preference.
